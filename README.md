# Баткомплект — электротовары для бизнеса

Локальная адаптивная страница по предоставленному референсу. HTML, CSS и JavaScript без фреймворка и без сборки. Все изображения и шрифты хранятся в проекте.

## Открыть страницу

Дважды нажмите `start.bat`. Скрипт запустит сервер в фоне и откроет http://localhost:4173. Для остановки используйте `stop.bat`.

Другой способ: выполните `npm start` в папке проекта. Для просмотра зависимости устанавливать не нужно — достаточно Node.js. Можно также открыть `index.html` напрямую; копирование текста в буфер лучше работает через локальный сервер.

## Что реализовано

- Композиция и порядок всех разделов референса, фирменные синий и оранжевый цвета, локальный шрифт Play с кириллицей.
- Семь предметных композиций 1536 × 1024. WebP-файлы для страницы и PNG-оригиналы в `assets/originals/`. Изображения используют `object-fit: contain`, без изменения пропорций.
- Адаптивная сетка, мобильное меню, плавное появление разделов, последовательное появление карточек, микродвижение первого экрана, анимация наведения и раскрытия FAQ.
- Уважение `prefers-reduced-motion`, доступные подписи, клавиатурная навигация и возврат фокуса из диалога.
- Поиск и категории ведут в соответствующие разделы действующего сайта. B2B, телефонные и почтовые ссылки рабочие.
- Форма проверяет поля и готовит письмо на `internet@batkomplekt.ru`. Пользователь отправляет его через свою почтовую программу. Файл необходимо добавить к письму самостоятельно, что явно указано в интерфейсе. Автоматической отправки на сервер и CRM-интеграции нет.

## Файлы

- `index.html` — разметка и контент.
- `styles.css` — оформление, адаптивность и анимация.
- `refinements.css` — обновлённые карточки, увеличенные отступы и оформление FAQ.
- `app.js` — меню, форма, FAQ-состояния браузера и эффекты.
- `assets/` — оптимизированные изображения, локальные шрифты и логотипы.
- `assets/image-prompts.json` — описание генерации и промпты изображений.
- `server.mjs` — сервер предпросмотра, слушает только локальный адрес.
- `tests/landing.spec.cjs` — браузерные проверки.
- `qa/desktop.png`, `qa/mobile.png` — снимки страницы для проверки.
- `qa/catalog.png`, `qa/faq.png` — крупные снимки обновлённых разделов.

## Обновление оформления

Для категорий подготовлены отдельные изображения с настоящей прозрачностью: `assets/*-cutout.webp`, PNG-исходники — `assets/cutouts/`. У товаров нет прямоугольной подложки; объекты вписаны в общий фон карточки без изменения пропорций. Первоначальные изображения сохранены отдельно.

Добавлены мягкая подсветка карточки под курсором, небольшой наклон и движение товаров, последовательное появление карточек, анимированные стрелки и подчёркивания навигации. Эффекты наведения включаются только для точного указателя, а настройка уменьшенной анимации отключает движения.

FAQ оформлен в две колонки с контактами и крупными вопросами. Открыт один ответ; раскрытие и закрытие плавные, повторные клики прерывают текущую анимацию без скачков. Нативные элементы `details` работают и без JavaScript.

## Проверка

```sh
npm install
npx playwright install chromium
npm run check
npm test
```

Проверки охватывают ширины 360, 390, 768, 1024, 1440 и 1920 px, отсутствие горизонтальной прокрутки, загрузку изображений и шрифта, меню, форму, файлы, FAQ, уменьшенную анимацию и доступность контента без JavaScript.

## Материалы

Источник фирменного логотипа, шрифта и логотипов производителей: https://www.batkomplekt.ru/. Композиции товаров созданы встроенным инструментом imagegen по мотивам референса, это иллюстрации категорий, а не фотографии конкретных артикулов. Исходный логотип сохранён в `assets/logo.svg`, версия с убранным пустым пространством и подписью — в `assets/brand.svg`.

## Публикация

Репозиторий: https://github.com/Moriarty32/batcomplekt

Страница публикуется через GitHub Pages из корня ветки `main`. Все пути к стилям, скриптам и изображениям относительные, поэтому страница работает в подпапке `/batcomplekt/`.

В репозитории находятся готовые WebP-изображения в полном разрешении. Тяжёлые PNG-оригиналы из `assets/originals/` и `assets/cutouts/` сохранены в локальной папке проекта и исключены из публикации.

Публичная форма, как и локальная, подготавливает письмо в почтовой программе посетителя; серверная отправка заявок не подключена.
